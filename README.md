# Blinkit-Sales-Analytics-Dashboard

## 📊 Project Overview
The Blinkit Sales Analytics Dashboard is an interactive Power BI project designed to analyze sales performance, product categories, outlet characteristics, and customer ratings. It transforms sales data into meaningful visual insights to support data-driven business decisions.

## 🎯 Project Objectives
- Analyze overall sales performance and key business metrics.
- Evaluate sales across different item categories.
- Compare outlet performance based on outlet type, size, and location tier.
- Understand customer ratings and product performance.
- Identify trends and patterns to support business analysis.

## 🛠️ Tools & Technologies
- **Power BI Desktop** – Dashboard development and visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculated measures and KPI analysis
- **Data Visualization** – Interactive charts, cards, and filters

## 📌 Key Performance Indicators (KPIs)
- Total Sales
- Average Sales
- Total Items
- Average Customer Rating

## 📈 Dashboard Features
- Interactive sales overview
- Sales analysis by item type
- Outlet-level sales comparison
- Outlet establishment and location analysis
- Dynamic filtering for exploring business performance
